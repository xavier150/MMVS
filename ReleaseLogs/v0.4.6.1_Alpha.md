# Macro Micro VR Service - Release Log
Release Logs: [GitHub Release Logs](https://github.com/xavier150/MMVS/wiki/Release-logs)


##  v0.4.6.1 Alpha (Talas Vore & Animations - Patch 1)
    - New: Click on game Version show detail in pause and main menus.
    - New: Better AI support for extreme scale on all characters types. (In engine unit from 0.1 to 1000 scale)
    - New: In desert map Talas damage value now use the scale difference.
        If Talas steps on you with a scale of 20, you will get 30 damage like before. But if Talas scales up to 40, you will get 240 damage. (This is experimental, an option to turn on/off is planned.)
    - New: when a teleport take too much time the game will show a loading screen.
    - New: New FX when character use teleporter.
    - New: Player gets camera impulse when Talas steps close to them. (Based on character scale difference and applied only in first person non-VR)
    - New: New stance icon when player want to stand up but blocked. (The player will automatically stand up when possible.)
    - New: Support for Cesium Ion (Not included in game but ready for mods using Cesium World.)
    - Change: Optimized footprint and step detection on Talas rug.
    - Change: Review AI behavior tree when Talas lay on bed with micro.
    - Change: AI decision chance Table is now renamed AI Personality Editor because the new AI options.
    - Change: Optimized AI Personality Editor code in C++
    - Change: During a teleport the character will disappear and reappear only when the teleport is finished.
    - Change: Big CPU optimization pass on Talas digestive system.
    - Change: The teleport room now show disabled remain teleporters with a red cross.
    - Fixed: The game opens the game tester info panel. (Should happen in testing build)
    - Fixed: Time to reform Talas rug is slower with low fps.
    - Fixed: New spawned character will hit all trigger like if it spawned with 1.0 scale. (A character with 0.1 should hit only his bound zone)
    - Fixed: Talas AI never enter in environment situations to play with micro like the bed or the sofa.
    - Fixed: Change "Stuck in Shoe" decisions chance don't have effect.
    - Fixed: Damages modes are shown in the wrong order in the start game menu.
    - Fixed: Talas left hand breaks if you do vore on floor after a grab.
    - Fixed: In desert level exit Talas digestive system may produce fatal error. (Digestive system timer that try to access non existing object.)
    - Fixed: In desert level move on long distance may produce fatal error. (World zone that lose reference on the level.)
    - Fixed: In desert level after a teleport you can fall through the ground.
    - Fixed: Memory leaks with digestive system animation + General pass on memory leaks.
    - Fixed: Digestive System collision have one frame delay latency.
    - Fixed: Camera shake location effect not scaled with character size.
    - Fixed: Camera shake location and rotation effect are now clamped to avoid extreme values.
    - Fixed: Talas AI can't run simple explore tasks when using a the sofa or the bed.
    - Fixed: Talas AI can't run close door tasks. (Wrong object reference)
    - Fixed: When two micros get stepped at the same time, only one can became stuck to the sole.
    - Fixed: When stuck to the sole or pinned underfoot the micro character is raised up. (This is because the Animation script that don't disable the foot IK)
    - Fixed: Cleanable footprints use the wrong interaction icon in UI. (Invalid action input)
    - Fixed: Game continue to show interactions FX and UI when the player is dead.
    - Fixed: Player can interact with environment objects when pinned.
    - Fixed: Player stands input don't react correctly after the player is forced to a specific stance.
    - Fixed: When Cobble is grab while he not standing up the release animation get bugged frames.
    - Fixed: Self Sight detection is inverted (Talas can see through his own body when should not.)
    - Fixed: Macro AI can't see micro when stuck in shoe.


## Techs
    - Character teleport system:
        - Refactorised settings structure to support override and config use.
        - Hardcoded settings are now set in config files.
        - Teleport UI and black screen interactions are now separated from the teleport system.

    - Digestive system:
        - Refactorised full digestive system tick management to increase CPU performance.
            From 120ms to 22ms on stress test, and 2ms in game per frame.
            +81.7% performance gain on digestive system tick.

    - New Floor Capture scripts used to detect footsteps on Talas rug and world level.
        - Moved old code from Blueprint to C++ for better performance and modularity.

    - Teleport:
        - Better teleport management with process states. 
            (Teleport Enter, Init Teleport, Teleport in transit, Teleport out transit, Teleport exit)
            - Better support for world partitions streaming and player movement states.
            - New loading screen when teleport takes too much time.
            - New FX when teleporting.
