##  v0.4.6 Alpha (Talas Vore & Animations)

    - New Teasing animations related to vore.
        - Maw exhibition 
        - Cobble flip in Talas beak
        - Talas lick Cobble
        - ...

    - New body react situation.
        - Talas can crouch to look closer at micro.

    - New: With Lumen Render in Talas House the zones without sun are less dark.
    - New: A new long third person view, (the camera distance can be much greater).
    - New: Better camera control for Game Master and Micro Characters.
    - New: Game Controls Options.
    - New: Support custom wrist, aim and grip positions. (OpenXR)
    - New: Support full hand tracking. (OpenXR)
    - New: Game code automatically detect VR finger tracking and switch at runtime.
    - New: Game ask game mode confirmation with a timer (VR / Non-VR) before automatically switch to the last game mode.
    - New: Better animations when stuck to sole. 
    - New: Better pose additive when rescale for inshoe, outsole and stuck to sole.
    - New: Better pose additive when rescale in VR.
    - New: Talas Shoes now have their own footprints.
    - New: Talas shoes offset with ground surface. (Offset from Talas IK)
    - New: Better render in Talas shoe.
    - New: Footsteps will do more damage if you are under the shoe and less damage if you are in the shoe.
    - New: Talas Decision Talas panel now show a panel to preview random weights.
    - New: You can now exit the ToyCar from either side depending on your look direction.
    - New: New cheat codes:
        - Set Max Health 
        - Set Max Health Regeneration.
        - Allow Negative Health.
        - Spawn blood photo mode object.
        - Out of Bounds Camera Distance.
    - New: Internal modding support:
        - New mod for applying character model replacement (Talas, Cobble, Tesy).
        - New Mod for applying Game Master cosmetic (Invisible or with Spot light).
    - Changes: All vore animations updated.
    - Changes: Game Master TPV camera can now go through the obstacles. (Useful to see under Talas sole.)
    - Changes: Better slider precision to choose a scale in the Debug Menu.
    - Changes: New game units (Kilotons, Megatons, Gigatons, Teratons)
    - Changes: Unit imperial system switch to metric when over one mega ton.
    - Changes: Grab system updated.
    - Changes: Better animation for fingers tracking.
    - Changes: Big optimization on the VR Net code, motion source and finger full tracking.
    - Changes: Better VR position in Talas beak. Avoid head outside.
    - Changes: VR UI now follow the wrist position and not the VR controller. (Better support for OpenXR use)
    - Changes: Disable collisions with player when release object in VR. (Avoid collision glitch)
    - Changes: Grab system use physical constraint now to grab objects in VR.
    - Changes: Grab VR zone is bigger.
    - Changes: New physical collisions to let Cobble Enter in beak outside an animation.
    - Changes: Macro and Shoe contact collisions optimized with better partial update.
    - Changes: New physical collisions and sweep collision detection for ToyCar wheels. (Sphere to Ray) Avoid invisible hits or bugs along walls.
    - Changes: Camera shake now use the player character location when the camera is close and the camera location when it is far from character.
    - Changes: Talas AI will sometimes wear his shoes.
    - Changes: Talas AI will sometimes show his house after grabbing a micro.
    - Changes: Talas AI will sometimes wear shoes when micro is stuck.
    - Changes: New decision pack for Talas AI when micro is stuck to outsole or in shoe.
    - Changes: Player minimum scale updated from 0.001 to 0.00001.
    - Changes: Character movement when lay on back keep body orientation in First Person View.
    - Changes: Kicks options to override AI decision was removed. (You can use the AI decision system for that now.)
    - Changes: Left and Right interactions to enter in ToyCar was replaced by a single interaction.
        (You will enter from right if you are on the right side, and same for the opposite.)
    - Changes: Turn the ToyCar back on wheels now use physics and not a teleport.
    - Changes: Better Toycar Engine sounds mixes.
    - Changes: The cheat code "Set Player Height" now use the player unit system (cm or feet).
    - Changes: Talas AI max view distance updated. (9000 -> 36000)

    - Engine Update: Unreal Engine 5.4.4 -> Unreal Engine 5.4.4 (Custom MMVS Build)

    - Character Grab System:

    - VR:
        - ...

    - Character config review and new character mod configs.

    - Game Modding:
        - New modding system to init, load and apply mods.
        - New mod config type (Character, Game Master or Level).
        - Support mod search and load from pak files. (Pak need to be build from MMVS Editor)

    - Refactoring of Situation System:
        - All source code moved to C++
        - Support multi characters.
        - Support master / slave control.
        - Net code moved to character Situation module.
        - Use Mesh as root for the offsets.

    - Refactoring of Stuck Zone System:
        - All source code moved to C++
        - Net code moved to character Stuck Zone module.
        - Use Mesh as root for the offsets.

    - Refactoring of Pinned Logic:
        - New Pinned module
        - All source code moved to C++
        - Net code moved to character Pinned module.

    - Refactoring of General Game settings:
        - Game Master, Session and UI Parameters more modular.
        - Optimization and fix Bugs.

    - Refactoring of AI decision system:
        - New AI Decision module.
        - Data structures moved to C++.
        - AI decision and relation are now fully modular.

    - Rig:
        - New Talas Rig for the tongue.

        - Move Object Outline code to C++ Plugin + Optimization pass.
