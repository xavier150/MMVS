## Techs
    - Engine Update: Unreal Engine 5.4.4 -> Unreal Engine 5.8.4
    - Audio Engine Update: Wwise Wwise 2024.1.8 -> Wwise 2025.1.11
    - Steam Audio Wwise Integration was removed.
    - Cesium plugin update: v2.21.0 -> v2.30.0
    - Kd-Tree plugin update: v1.3 -> v1.7
    - Updated VaRest plugin: v?.? -> v1.2
    - New calculation for VR Rendering Resolution.
        (vr.PixelDensity removed)

    - Teleport Room:
        - Teleport room now use Level Instance instead of an BP actor with child actor components.
        - Better support of the World Partition system. (No need to keep the teleport room always loaded when not in use)

    - Game Master:
        - Game Master Selection
        - Removed old "GamePlay Visual Preview" system, now fully replaced by the new "Game Master Visual Preview".
            (Game Master Visual Preview was added in v0.4.7)
        - Game Master Controller now use modular sub modules for better flexibility.
            (PGM_3dMouse, PGM_Outline, PGM_ActionControl, etc.)

    - IK management:
        - Full Body IK Control rigs are now set on the character with Anim Layer.
            (This avoid a raw character switch and it increases the performances)

    - Macro Interaction System:
        - The foot interactions was reviewed to separate pinned interaction (When the micro is pinned by the foot.) from damage interactions.
        (Before the crush FX and sound was triggered by the damage system, but the uncrush was triggered by the pinned system. Now both are managed by the body damage system.)
        - The rear interactions (When the micro is pinned because a macro sat on them.) were also reviewed to standardize as the foot interactions.
            (Foot and rear interactions now follow the same logic for pinned and damage interactions.)

    - Game Master:
        - Game Master Interaction Net code was moved to C++.
        - Game Master Interaction are more modular and now use interfaces for generic actions.

    - Massive cleanup of old deprecated systems, code, and assets.
