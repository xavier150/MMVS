##  v0.4.5.1 Alpha (Talas Vore & Stomach Tour)

    - New Teasing animations related to vore.
        - Maw exhibition 
        - Cobble flip in Talas beak
        - Talas lick Cobble
        - ...
        
    - New body react situation.
        - Talas can crouch to look closer at micro.

    - New: With Lumen Render in Talas House the zones without sun are less dark.
    - New: A third person view, the camera distance can be much greater.
    - New: Better camera control for Game Master and Micro Characters.
    - New: Game Controls Options.
    - New: Support custom wrist, aim and grip positions. (OpenXR)
    - New: Support full hand tracking. (OpenXR)
    - New: Game code automaticaly detect VR finger tracking and switch at runtime.
    - Changes: All vore animations updated.
    - Changes: Game Master TPV camera can now go through the obstacles. (Useful to see under Talas sole.)
    - Changes: Better slider precision for choose a scale in the Debug Menu.
    - Changes: New game units (Kilotons, Megatons, Gigatons, Teratons)
    - Changes: Unit imperial system switch to metric when over one mega ton.
    - Changes: Grab system updated.
    - Changes: Better animation for fingers tracking.
    - Changes: Big optimization on the VR Net code, motion source and finger full tracking.
    - Changes: Better VR position in Talas beak. Avoid head outside.
    - Changes: VR UI now follow the wrist position and not the VR controller. (Better support for OpenXR use)
    - Changes: Disable collisions with player when release object in VR. (Avoid collision glitch)
    - Changes: Grab system use physical constraint now to grab objects in VR.
    - Changes: Grab VR zone is bigger.
    - Changes: New physical collisions to let Cobble Enter in beak outside an animation.
    - Changes: Macro and Shoe contact collisions optimizated with better partial update.
    - Changes: New physical collisions and sweep collision detection for ToyCar wheels. (Sphere to Ray) Avoid invisible hits or bugs along walls.
    - Fixed: Talas Tongue is Gray.
    - Fixed: Desktop users see other player VR laser pointer when in menu.
    - Fixed: Slomo option in Debug Menu doesn't update when value is changed.
    - Fixed: Character Relative World Calculation Mass is wrong.
    - Fixed: Game Crash when character over 100000 scale with debug menu open. (Unit calculation fail with tons.)
    - Fixed: Is not possible to Zoom in Game Master.
    - Fixed: Camera Near Clip do not update when character respawn.
    - Fixed: Game Crash using Oculus or HTC App. (Game try to access finger tracking data that not avaiable.)
    - Fixed: VR Hand Animation not updated when finger tracking is On. (The animation code don't check is the finger tracking is really avaialble.)
    - Fixed: VR Finger switch On/Off need game restart to apply or switch Desktop/VR.
    - Fixed: VR Finger don't offset with hand wrist.
    - Fixed: VR offset on server side is wrong when player turn around.
    - Fixed: VR left hand Rumble on right when grab.
    - Fixed: VR hands still visible when stuck to sole with "Show Body when Stuck" option.
    - Fixed: TPV body alway visible when stuck in hand or in beak with "Show Body when Stuck" option.
    - Fixed: TPV body is not lock when stuck.
    - Fixed: The final builds contain debug log files. (1,7 GB free space saved without .pdb files. Thanks Eliyar) 
    - Fixed: Character eye darts and eye blink don't work when in situation. 
    - Fixed: Slime FX break when the end point is not visible. (Should not break only if the bound start/end points is not visible.)
    - Fixed: Slime FX break too quicly when not visible. (Before 0.2s, now 3.0s)
    - Fixed: Slime FX may don't spawn when no link set (Bound size get zero so considered as not visible and link that should update the bound is never spawn.)
    - Fixed: Physical cheats codes do not work well.
