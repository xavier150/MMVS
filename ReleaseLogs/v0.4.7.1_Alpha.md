# Macro Micro VR Service - Release Log
Release Logs: [GitHub Release Logs](https://github.com/xavier150/MMVS/wiki/Release-logs)


##  v0.4.7.1 Alpha (Talas Vore & Sound Design)
    - New: New option in AI personality settings for character situation. (Sit on the floor, or stand against a wall)
    - Fixed: IK Manager ignore list don't include the owner and character capsule ignore list.
        (This make Talas paws rotate on objects that should be ignored.)
    - Fixed: Some commands or cheat codes are not working.
        (The GameState script is not notified by player chat messages)
    - Fixed: Talas AI receiving a failed interaction when try to move at the same X/Y location.
    - Fixed: Talas AI don't alway set down the micro when stand against a wall.
    - Fixed: When play as client in multiplayer with high latency, you may get a Fatal Error due to situation system desynchronization.
        (This happens because the client may attempt to apply the end of an enter situation while the server sent a exit situation event.)
