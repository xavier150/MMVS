# Macro Micro VR Service - Release Log
Release Logs: [GitHub Release Logs](https://github.com/xavier150/MMVS/wiki/Release-logs)


##  v0.4.7.1 Alpha (Talas Vore & Sound Design)
    - New: An option in AI personality settings for character situation. (Sit on the floor or stand against a wall)
    - New: MMVS now supports Portuguese (Portuguese)
    - New: MMVS now supports Traditional Chinese (繁體中文)
    - New: Physics Based Lighting settings for Telporters.
        (For the moment, these are used only in Cesium level to avoid teleporters appearing fully dark in EarthToy mod.)
    - Changed: Removed all country flags to avoid political sensitivity.
        (The flags were replaced with an icon showing the language code.)
    - Fixed: IK Manager ignore list doesn't include the owner or the character capsule.
        (This makes Talas's paws rotate on objects that should be ignored.)
    - Fixed: Some commands or cheat codes are not working.
        (The GameState script is not notified by player chat messages.)
    - Fixed: Talas AI receiving a failed interaction when trying to move to the same X/Y location.
    - Fixed: Talas AI doesn't always set down the micro when standing against a wall.
    - Fixed: When playing as a client in multiplayer with high latency, you may get a fatal error due to situation system desynchronization.
        (This happens because the client may attempt to apply the end of an enter situation while the server sends an exit situation event.)
    - Fixed: VR view offset is wrong, causing clipping into Talas's tongue.
        (The camera should automatically adjust to avoid clipping into Talas's tongue.)
    - Fixed: In VR, the camera near clip is too far.
        (The near clip plane is set too far from the camera, causing nearby objects to be clipped prematurely.)
    - Fixed: In VR, the camera near clip is not updated with character scale.
        (The near clip plane should be updated according to the character's scale. Small clipping when player is small, large clipping when player is large.)
    - Fixed: When very small, you can't touch the teleporter.
        (The trigger collision was not touching the floor and small characters can't touch it.)
    - Fixed: Talas AI runs the "Stuck to Sole" branch when the micro is stuck to the shoe outsole.
        (The AI should run the "Stuck to Outsole" branch, not the "Stuck to Sole" branch.)
    - Fixed: Talas AI always fails to peel the micro from the shoe outsole.
        (Internal code checks the list of micros stuck to the bare foot sole instead of the shoe outsole.)
    - Fixed: In VR, the virtual VR Keyboard doesn't appear in the Pause/Main Menu.
    - Fixed: Some translation and localization issues.
    - Fixed: Linux build (Linux, Linux_Arm64) doesn't create any crash reports when the game crashes.
        (bAgreeToCrashUpload is not forced True.)
    - Fixed: Linux dedicated server crash when a player switches to VR.
        (The VR switch triggers a settings update in a function that doesn't exist on the dedicated server.)
    - Fixed: VR Player can spawn lying down on Cobble bed.
        (The VR player shares the VR state with the server too late.)
    - Fixed: Desert Ambience play some random sounds to add variety, but the volume was too high.
    - Fixed: The option "Animation Speed Scale" is added twice in the Game Master menu on multiplayer clients.
    - Fixed: The option "Damage Mode" appears in the wrong game master category.
    - Fixed: Talas Player State is not destroyed properly when Talas is respawned.
        (Conflict in internal dependencies)
    - Fixed: Cesium Sky badly initialized at spawn.
        (This fixes the EarthToy mod visual glitch in the sky for some presets.)
