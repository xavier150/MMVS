##  v0.4.7 Alpha (Talas Vore & Sound Design)
    - New sound design related to vore.
    - New: New notification sound when the Player avoids getting spotted by Macro AI.
    - New: Desert level now has ambient sounds.
    - New: New localized sounds for the Cozy House doors.
    - New: Ambient sounds in the pipes of Cozy House level were redone.
    - New: Talas House now has new ambient sounds with room-specific variations.
    - New: Talas digestive system now has ambient sounds with variations.
    - New: New sound for success and fail interaction feedback.
    - New: Step sounds now use a true blending depending on the step weight and speed.
    - New: Sticky sounds for footsteps in the Talas digestive system.
    - New: Sound attenuation is scaled with the character scale. (Footsteps, Voices, etc.)
    - New: Text property UI will automatically scroll left and right when the text is too long to be fully visible.
        (Fixes many issues when the localized text is too long and when the game window is too small.)
    - New: New and reviewed surface types on the geometry for the footstep sounds.
    - New: Added new rescale pads to rescale characters and cheat codes to spawn them.
    - New: New hidden cheat codes in levels.
    - New: New game master tool to show Talas maw.
    - New: AI branch to break out when Talas is stuck in a wall or on furniture.
    - New: Cobble arms animations are smoother.
    - New: Vore and Maw Exhib animation transitions are now smoother.
        (Abrupt transitions and teleportations due to attachments are now replaced with interpolated smooth transitions.)
    - New: Audio mono setting.
    - New: Background Audio setting.
        (When active, automatically mute the audio when the game is running in the background.)
    - New: Better doppler effect.
    - New: Support for maintained movement and input.
        - Maintained Movement: Applies the last character movement, 
        - Maintained Input: Applies the last movement action input
    - New: New Audio effect when the camera is under the floor.
    - New: You can now switch to Game Master in Talas digestive system.
        (That was possible before but the render was updated only every 1 second because of player collision detection)
    - New: You can now hear the world sounds when you are in Talas digestive system. 
        (Like the footsteps of Talas when he walks, the ambient sounds, etc.)
    - New: Talas now has a dynamic heart system.
        (Heartbeat speed changes depending on his activity and situation, with synchronized animations and audio in the digestive system.)
    - New: Talas digestive system will move with Talas movement and steps.
    - New: When the player gets grabbed with hand or beak, the teleport transition was replaced by a linear movement to avoid the teleport effect.
    - New: In multiplayer, new players spawn lying in Cobble bed if not occupied.
        (Before that was only the host player at level load)
    - New: New animation for Control and Tooltip UI overlays.
    - New: You can now turn off the physics light balls in the desert level and they are off by default.
    - New: In Graphics settings new "Very Low" and "Very High" presets.
    - New: New animation and AI interactions for the Maw Showing. 
    - New: New tab and sections in the pause menu to avoid too many options on the same page.
    - New: New F12 input to take screenshot with the current game resolution.
        (Hold F12 is now used to take UHD screenshots.)
    - New: When the game takes a screenshot, it will also create a compressed version of the screenshot.
    - New: New 360 screen when you are pinned under Talas shoe, inside the shoe, when Talas sits on you.
    - New: In the digestive system, you can now grab and pull the flesh walls.
        (Players can interact with and pull flesh walls to open passages.)
    - New: In Talas digestive system, the flesh walls are now pushed with the player's movement and camera.
        (This makes it more organic and it avoids camera clipping issues.)
    - New: Better Water effects for the digestive fluids. (Audio, Visual and collision detection)
    - New: New dissolve sound when in digestive fluids.
    - New: You can now show Talas animations without changing the time dilation.
        (Option available in the Game Master menu.)
    - Change: Optimized collision for CPU and sound
        (Wall bricks, Talas bed, Shelves, etc.)
    - Change: All debug contextual feedback updated with correct grammar.
    - Change: Added objects and collision to help player exploration in Cozy House level.
    - Change: All game master FX were reviewed and made smoother.
    - Change: The floating player name above the head now supports most character types.
        (Text Render was replaced by a widget texture to support more font and designs.)
    - Change: Talas now predicts the player position using the last known velocity when he loses sight of him.
        (For the moment this is only used for the stomp and grab interactions.)
    - Change: Redid Audio Settings (Ambiance removed, Gameplay Feedback and Orbs added) + New audio hierarchy preview.

    - Change: Game Chat menu can only be opened when pause menu is closed.

    - Change: Animations are more stable and shake less.

    - Change: Animations are now synced with the server. Avoids misplaced footsteps and footprints in multiplayer.
        (Animations Sync Groups reset when not used. So they resync with the character actions and stay synced in multiplayer.)
    - Change: Player camera impulse disabled when pinned under paw.
        (Avoids breaking the immersion when trampled while looking at the sole.)
    - Change: Force resistance duration in the digestive system is longer.
        (If you try to move, the digestive system will stop pushing you for 12 seconds instead of 6 seconds.)
    - Change: Removed footprint in the digestive system.

## Game Settings Details
    - VR Settings:
        - "VR Hands" has been renamed to "Preferred VR Mode" 
        - "Show Body When Stuck to Sole" has been replaced by "Preferred VR Mode When Stuck" and "Preferred VR Mode In Vehicle"
            (This is more intuitive and it lets the player choose the preferred VR mode in different situations.)
    - Ergonomic Settings (Interface):
        - New control to show your own name.
    - Audio Settings:
        - New sub control for Orb sounds.
        - New mono audio output option.
        - New option to disable audio when the game is in the background.
    - Graphics Settings:
        - New: "Global Quality Option" have been replaced by a "Quality Preset" with new "Very Low" and "Very High" presets.
        

## Techs
    - Player AI feedback system:
        - All code related to player detection by Macro AI has been refactored and moved to a dedicated module.

    - Audio Design 
        - First update on the native engine:
            - All Sound Cues have been redone to use MetaSounds Sources.
            - Old sound class override in sound mix was replaced by Audio modulation and Sound Control Bus mix for the volume settings.
            - All AudioVolume actors were replaced by the new AudioGameplayVolume.
            - MMVS now uses the Submix system to manage sound effects.

        - Second update on the Wwise integration:
            - New: Advanced audio propagation through rooms and portals.
                (Sounds can now propagate between rooms through the doors and holes.)
            - Audio Engine Update: Unreal Engine 5.4.4 -> Wwise 2022.1.19 -> Wwise 2024.1.8
            - The full audio system has been reworked to use Wwise features:
                - Some features are still used like the Sound Control Bus but this time it's used to control Wwise.
            - New effect system.
            - New doppler effect scalable with player & environment scale.

    - Debug menus:
        - New debug menu for music
        - New debug menu for Audio
        - New AI contextual feedback debug menu. 
            (Like in the main debug menu but only for the AI feedback.)
        - Calibrator moved to a new menu specific to the calibrator.
    
    - Interaction system:
        - More modular interaction script with interaction state and script modifiers.
            (Can easily plug modifiers into an interaction without creating a custom class for each interaction.)
        - Interaction script for communication between scripts was moved to C++.
        - Interactions now support action types (Press, Release, etc.)
        - Interactions now support post interaction states. (Held interaction, by whom, etc.)

    - Game Master:
        - Full refactoring of the game master root code.
        - Root code moved from blueprint to C++.
        - Support for multiple game masters in a same game in the root code.
            (Full support planned in the future)
        - New game master observers, selections and tools to make dev use user-friendly.
        - New Fx management.

    - Tracking Point System:
        - Base script was moved from blueprint to C++ and now supports custom movement modifiers. 
            (Like the interaction system, useful when a game master or AI uses custom movement to follow a target or animate the movement to a specific point.)
        - Optimized method calculation to check if in zone and better zone shape management.
        - Supports a Preview System to manage effects and preview tracking movement without impacting the true tracking point transform.

    - Perception Tracking Proxy:
        - Moved from blueprint to C++ and now supports new movement methods with velocity follow.

    - Digestive System:
        The Digestive system is now split into three different modules:
        - TagDynamicMeshMorph to manage the physical, collision, and rendering mesh morphing.
        - TagDigestiveSystem to manage the digestive system logic and interactions.
        - TalasDigestiveSystem to manage Talas digestive system specific logic and assets.
        Big refactoring of the section management and tick management.
        New dynamic audio listeners for world sounds when you are in the digestive system. 

    - Quick Time Event System: (Used for game entry and respawn)
        - All the system was moved from blueprint to C++
            (The system was originally hard coded in the player controller blueprint, it is now modular and can be used for multiple situations.)
        - The system now supports multiple QTEs at the same time.
        
    - Chat and Notification System:
        - The system was moved from blueprint to C++
        - The sender and message can be updated at runtime.
