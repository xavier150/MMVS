    - New: Desert level have now an ambient sounds.
    - New: New localized sounds for the Cozy House doors.
    - New: Ambient sounds in the pipes of Cozy House level where redo using soundscapes.
    - New: New sound for success and fail interactions feedback.
    - New: Step sounds now use a true blending depending on the step weight and speed.
    - New: Sound attenuations is scaled with the character scale. (Footsteps, Voices, etc.)

    - Fixed: Talas AI perception ingore micro distance and detect like if the micro is always front of him.

## Game Settings Details
    - VR Settings:
        - "VR Hands" have been renamed "Preferred VR Mode" 
        - "Show Body When Stuck to Sole" have been replaced by "Preferred VR Mode When Stuck" and "Preferred VR Mode In Vehicle"
            (This is move intuitive and it let the player choose the preferred VR mode in different situations.)

## Techs
    - Player AI feedback system:
        - All code related to player detection by Macro AI has been refactorised and moved to a dedicated module.

    - Audio Design 
        - First update on the native engine:
            - All Sound Cue have been redo to use MetaSounds Sources.
            - Old sound class override in sound mix was replaced by Audio modulation and Sound Control Bus mix for the volume settings.
            - All AudioVolume actors were replaced by the new AudioGameplayVolume.
            - MMVS now use the Submix system to manage sound effects.

        - Second update on the Wwise integration:
            - Audio Engine Update: Unreal Engine 5.4.4 -> Wwise 2022.1.19 -> Wwise 2024.1.8
            - The full audio system have been reworked to use Wwise features:
                - Some features are still used like the Sound Control Bus but this time it's used to control Wwise.
